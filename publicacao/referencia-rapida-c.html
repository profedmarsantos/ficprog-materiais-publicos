Mural de Código C

Pegue a dica certa, use no programa e teste.

Roteiro: declare → leia → calcule → mostre. Sempre faça um teste de mesa antes de concluir.

Post-it 01 · Tipos

Que tipo de valor vou guardar?

Post-it 02 · Mapa dos formatos

O formato depende do comando.

Tiposcanfprintf
int%d%d
float%f%f
double%lf%f
char%c%c

Post-it 03 · Declarar e ler

Prepare as variáveis e peça os dados.

int quantidade;
float preco;
double medida;
char letra;

scanf("%d", &quantidade);
scanf("%f", &preco);
scanf("%lf", &medida);
scanf(" %c", &letra);

& vai antes da variável. O espaço em " %c" ignora uma quebra de linha anterior.

Post-it 04 · printf com texto

Só uma mensagem? Não use formato.

printf("Olá, turma!\n");
printf("Digite a quantidade: ");

\n pula para a próxima linha. Aqui não há variável depois da vírgula.

Post-it 05 · printf com variável

Formato no texto + variável após a vírgula.

printf("Qtd.: %d\n", quantidade);
printf("Preço: %.2f\n", preco);
printf("Medida: %.3f\n", medida);
printf("Letra: %c\n", letra);

A ordem das variáveis deve acompanhar a ordem dos formatos.

Post-it 06 · Decimais e vírgula

Escolha quantas casas quer mostrar.

printf("%.1f", preco);  /* 7.5 */
printf("%.2f", preco);  /* 7.50 */
printf("%.3f", preco);  /* 7.500 */

Neste módulo, use ponto nos valores decimais: 7.50.

Post-it 07 · Calcular

Guarde o resultado em uma variável.

total = quantidade * preco;
total = taxa + (consumo * preco);

= atribui. Use +, -, * e / nos cálculos; parênteses deixam a intenção clara.

Post-it 08 · Checklist final

Antes de executar, confira:

  • tipo certo para cada dado;
  • formato certo no scanf;
  • formato e variável na mesma ordem no printf;
  • resultado previsto no teste de mesa.
Sequência de trabalho: problema → pseudocódigo → C → execução → depuração/teste de mesa.
