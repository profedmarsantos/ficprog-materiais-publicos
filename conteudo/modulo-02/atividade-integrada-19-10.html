Exercício 1 — Caixas de parafusos

Resposta esperada: A divisão inteira fornece 10 caixas e o resto fornece 7 parafusos.

Pseudocódigo estruturado

VAR
    inteiro total, capacidade, caixas, sobra
INÍCIO
    leia(total, capacidade)
    caixas <- total / capacidade
    sobra <- total % capacidade
    escreva(caixas, sobra)
FIM

Programa C completo

#include <stdio.h>

int main(void) {
    int total, capacidade, caixas, sobra;
    scanf("%d %d", &total, &capacidade);
    caixas = total / capacidade;
    sobra = total % capacidade;
    printf("Caixas: %d; sobra: %d\n", caixas, sobra);
    return 0;
}

Teste de mesa e depuração

Após ler 127 e 12, 127 / 12 vale 10 no tipo int; 127 % 12 vale 7. Confira 10 × 12 + 7 = 127. Se a sobra for 0, todas as caixas ficam completas.

Exercício 2 — Média de três medições

Resposta esperada: A soma é 24; dividida por 3 produz 8.00.

Pseudocódigo estruturado

VAR
    real a, b, c, media
INÍCIO
    leia(a, b, c)
    media <- (a + b + c) / 3
    escreva(media)
FIM

Programa C completo

#include <stdio.h>

int main(void) {
    float a, b, c, media;
    scanf("%f %f %f", &a, &b, &c);
    media = (a + b + c) / 3.0f;
    printf("Media: %.2f\n", media);
    return 0;
}

Teste de mesa e depuração

Depois da leitura, a=7, b=8 e c=9. A soma entre parênteses vale 24; media recebe 8. Compare com a expressão sem parênteses, que soma 7 + 8 + 9/3 e dá 18, um erro lógico.

Exercício 3 — Pagamento de horas extras

Resposta esperada: 740.00 pelas horas normais mais 55.50 pelas extras totalizam 795.50.

Pseudocódigo estruturado

VAR
    inteiro normais, extras
    real valorHora, total
INÍCIO
    leia(normais, extras, valorHora)
    total <- normais * valorHora + extras * valorHora * 1,5
    escreva(total)
FIM

Programa C completo

#include <stdio.h>

int main(void) {
    int normais, extras;
    float valorHora, total;
    scanf("%d %d %f", &normais, &extras, &valorHora);
    total = normais * valorHora + extras * valorHora * 1.5f;
    printf("Pagamento: R$ %.2f\n", total);
    return 0;
}

Teste de mesa e depuração

40 × 18.50 = 740.00; 2 × 18.50 × 1.5 = 55.50; total=795.50. O adicional incide somente sobre as horas extras.

Exercício 4 — Duração em horas, minutos e segundos

Resposta esperada: 3600 segundos formam uma hora; restam 72, isto é, 1 minuto e 12 segundos.

Pseudocódigo estruturado

VAR
    inteiro total, horas, minutos, segundos
INÍCIO
    leia(total)
    horas <- total / 3600
    minutos <- (total % 3600) / 60
    segundos <- total % 60
    escreva(horas, minutos, segundos)
FIM

Programa C completo

#include <stdio.h>

int main(void) {
    int total, horas, minutos, segundos;
    scanf("%d", &total);
    horas = total / 3600;
    minutos = (total % 3600) / 60;
    segundos = total % 60;
    printf("%d h %d min %d s\n", horas, minutos, segundos);
    return 0;
}

Teste de mesa e depuração

3672 / 3600 = 1; 3672 % 3600 = 72; 72 / 60 = 1; 3672 % 60 = 12. Reconstrua: 1×3600 + 1×60 + 12 = 3672.

Desafio opcional — Desconto em uma compra

Resposta esperada: O percentual é dividido por 100 antes de multiplicar pelo subtotal.

Pseudocódigo estruturado

VAR
    inteiro quantidade
    real preco, percentual, subtotal, desconto, total
INÍCIO
    leia(quantidade, preco, percentual)
    subtotal <- quantidade * preco
    desconto <- subtotal * percentual / 100
    total <- subtotal - desconto
    escreva(subtotal, desconto, total)
FIM

Programa C completo

#include <stdio.h>

int main(void) {
    int quantidade;
    float preco, percentual, subtotal, desconto, total;
    scanf("%d %f %f", &quantidade, &preco, &percentual);
    subtotal = quantidade * preco;
    desconto = subtotal * percentual / 100.0f;
    total = subtotal - desconto;
    printf("Subtotal: R$ %.2f; desconto: R$ %.2f; total: R$ %.2f\n",
           subtotal, desconto, total);
    return 0;
}

Teste de mesa e depuração

subtotal=3×12.50=37.50; desconto=37.50×10/100=3.75; total=33.75. A ordem das atribuições importa: total usa desconto já calculado.
