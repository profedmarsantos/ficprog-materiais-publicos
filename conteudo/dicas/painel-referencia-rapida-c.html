Mural de Código C

Pegue a dica certa, use no programa e teste.

Roteiro: declare → leia → calcule → mostre. Sempre faça um teste de mesa antes de concluir.

Post-it 01 · Tipos

Que tipo de valor vou guardar?

intinteiros7, 25, -3
floatdecimais7.5, 0.25

Post-it 02 · Mapa dos formatos

O formato depende do comando.

Tiposcanfprintf
int%d%d
float%f%f

Post-it 03 · Declarar e ler

Prepare as variáveis e peça os dados.

int quantidade;
float preco;

scanf("%d", &quantidade);
scanf("%f", &preco);

& vai antes da variável.

Post-it 04 · printf com texto

Só uma mensagem? Não use formato.

printf("Olá, turma!\n");
printf("Digite a quantidade: ");

\n pula para a próxima linha. Aqui não há variável depois da vírgula.

Post-it 05 · printf com variável

Formato no texto + variável após a vírgula.

printf("Qtd.: %d\n", quantidade);
printf("Preço: %.2f\n", preco);

A ordem das variáveis deve acompanhar a ordem dos formatos.

Post-it 06 · Decimais e vírgula

Escolha quantas casas quer mostrar.

printf("%.1f", preco);  /* 7.5 */
printf("%.2f", preco);  /* 7.50 */
printf("%.3f", preco);  /* 7.500 */

Em entradas de teste, use ponto nos valores decimais: 7.50.

Post-it 07 · Calcular

Guarde o resultado em uma variável.

total = quantidade * preco;
total = taxa + (consumo * preco);

= atribui. Use +, -, * e / nos cálculos; parênteses deixam a intenção clara.

Post-it 08 · Checklist final

Antes de executar, confira:

  • tipo certo para cada dado;
  • formato certo no scanf;
  • formato e variável na mesma ordem no printf;
  • resultado previsto no teste de mesa.

Módulo 02

Tipos e expressões

int, float, precedência e divisão inteira

int metade = 5 / 2;       /* 2 */
float media = (a + b) / 2.0f;
int resto = 7 % 3;        /* 1 */

Use parênteses para deixar a conta clara. Divisão entre inteiros descarta a parte fracionária.

Módulo 03

Sequência e organização

Múltiplas entradas e saídas

scanf("%d %f", &quantidade, &preco);
total = quantidade * preco;
printf("Total: %.2f\n", total);

Declare, leia, calcule e mostre nessa ordem. Confira cada valor no teste de mesa.

Módulo 04

Decisões

Comparações e caminhos

if (media >= 6.0f) {
    printf("Aprovado\n");
} else if (media >= 4.0f) {
    printf("Recuperacao\n");
} else {
    printf("Reprovado\n");
}

Use == para comparar igualdade; = atribui. && exige duas condições; || aceita uma delas. switch pode selecionar alternativas por valor inteiro.

Módulo 05

Repetições

Escolha o laço pelo problema

for (i = 0; i < 5; i++) { soma += valor; }
while (valor != 0) { scanf("%d", &valor); }
do { scanf("%d", &opcao); } while (opcao != 0);

for serve para contagem conhecida; while testa antes; do...while executa ao menos uma vez. Atualize a variável de controle.

Módulo 06

Vetores

Índices e percurso

int leituras[5];
for (i = 0; i < 5; i++) {
    scanf("%d", &leituras[i]);
}

Em um vetor de cinco posições, os índices válidos são 0, 1, 2, 3 e 4. Não acesse a posição 5.

Módulo 07

Funções

Parâmetros e retorno

int dobro(int valor) {
    return 2 * valor;
}
/* uso: resultado = dobro(3); */

Parâmetros recebem os dados da chamada. Uma função com tipo de retorno entrega um valor; um procedimento void executa uma ação sem devolver valor.

Módulo 08

Integração

Combine recursos já estudados

Para problemas como caixa eletrônico e estacionamento, separe entradas, regras, estado que muda e saídas. Faça casos normais, limites e recusas. Combine decisões, laços, vetores e funções simples somente quando ajudarem a explicar a solução.

Arduino no Tinkercad é exploração opcional do Módulo 8; as funções próprias desse ambiente não integram este painel de C introdutório.

Sequência de trabalho: problema → representação → C → execução → depuração/teste de mesa. Pseudocódigo estruturado é exigido apenas nos módulos 1 e 2.
