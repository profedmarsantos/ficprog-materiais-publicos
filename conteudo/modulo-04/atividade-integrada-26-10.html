Atividade Presencial — Módulo 4

2 h · Estruturas condicionais e operadores lógicos · 26/10/2026

Objetivo. Analisar condições e implementar decisões com operadores relacionais e lógicos.

Este módulo compartilha as 2 horas presenciais do encontro com o Módulo 3. O professor selecionará os exercícios a trabalhar em aula; os demais ficam para estudo e retomada.

Como resolver cada exercício

  1. Complete o quadro Entrada → Processamento → Saída.
  2. Esboce a lógica se isso ajudar; a escrita formal de pseudocódigo não é obrigatória.
  3. Implemente a solução em C com os recursos estudados até este módulo.
  4. Execute o programa com o caso de teste indicado e registre a saída.
  5. Faça o teste de mesa e compare a saída obtida com o resultado esperado.

Organização: são quatro exercícios e um desafio opcional. A lista é um repertório para seleção do professor, não uma exigência de resolver todos durante as 2 horas do encontro.

Exercício 1 — Aprovação por média

Leia uma média real de 0 a 10. Mostre 'Aprovado' se a média for pelo menos 6.0; caso contrário, mostre 'Em recuperacao'.

EntradaProcessamentoSaída
Média final do estudante (float, entre 0 e 10).Comparar a média com 6.0; se for maior ou igual, aprovar; caso contrário, indicar recuperação.Exibir exatamente “Aprovado” ou “Em recuperacao”.

Caso de teste: média 6.0 → resultado esperado: Aprovado

Exercício 2 — Faixa de temperatura de máquina

Leia uma temperatura real em Celsius. Classifique: abaixo de 20 como 'Baixa'; de 20 até 70 inclusive como 'Normal'; acima de 70 como 'Alta'.

EntradaProcessamentoSaída
Temperatura da máquina em graus Celsius (float).Se a temperatura for menor que 20, classificar como Baixa; de 20 a 70 inclusive, Normal; acima de 70, Alta.Exibir uma das faixas: “Baixa”, “Normal” ou “Alta”.

Caso de teste: 70.0 C → resultado esperado: Normal

Exercício 3 — Código de sensor válido

Leia uma leitura inteira. Códigos entre 0 e 1023, inclusive, são válidos; qualquer outro é inválido. Use operador lógico para testar as duas fronteiras.

EntradaProcessamentoSaída
Código de leitura do sensor (int).Verificar conjuntamente as fronteiras: código maior ou igual a 0 e menor ou igual a 1023.Exibir “Valido” para código dentro da faixa ou “Invalido” fora dela.

Caso de teste: 1023 → resultado esperado: Valido

Exercício 4 — Prioridade de atendimento

Leia idade inteira não negativa e indicador inteiro de deficiência (0=não, 1=sim). Mostre 'Prioritario' se a idade for pelo menos 60 ou se houver deficiência; senão, 'Comum'.

EntradaProcessamentoSaída
Idade em anos (int, não negativa) e indicador de deficiência (int: 0 para não; 1 para sim).Verificar se idade é pelo menos 60 ou se o indicador de deficiência é 1; basta uma condição verdadeira.Exibir “Prioritario” quando houver prioridade; caso contrário, “Comum”.

Caso de teste: idade 35, deficiência 1 → resultado esperado: Prioritario

Desafio opcional — Frete por região

Leia uma opção inteira de região: 1 para retirada no campus, 2 para cidade, 3 para outra cidade. Mostre o frete fixo R$ 0.00, R$ 8.00 ou R$ 15.00, respectivamente; para outra opção, mostre 'Opcao invalida'.

Caso de teste: opção 3 → resultado esperado: Frete: R$ 15.00

Entrega e conferência

Para os exercícios selecionados, mostre a análise do problema, o programa C, a saída obtida e um teste de mesa que explique o valor das variáveis. A escrita formal de pseudocódigo não é exigida.

Gabarito

Abra cada solução depois da tentativa dos estudantes. Os programas usam apenas os recursos introdutórios estudados até este módulo.

Exercício 1 — Aprovação por média

Resposta esperada: O limite 6.0 pertence ao ramo de aprovação.

#include <stdio.h>

int main(void) {
    float media;

    if (media >= 6.0f) {
        printf("Aprovado\n");
    } else {
        printf("Em recuperacao\n");
    }
    return 0;
}

Exercício 2 — Faixa de temperatura de máquina

Resposta esperada: 70.0 integra a faixa normal; acima desse valor é alta.

#include <stdio.h>

int main(void) {
    float temperatura;
    scanf("%f", &temperatura);
    if (temperatura < 20.0f) {
        printf("Baixa\n");
    } else if (temperatura <= 70.0f) {
        printf("Normal\n");
    } else {
        printf("Alta\n");
    }
    return 0;
}

Exercício 4 — Prioridade de atendimento

Desafio opcional — Frete por região

Resposta esperada: A opção 3 seleciona o terceiro valor fixo; outras opções não têm frete calculado.

    } else if (regiao == 3) {
