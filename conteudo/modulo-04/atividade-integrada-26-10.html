Exercício 1 — Aprovação por média

Resposta esperada: O limite 6.0 pertence ao ramo de aprovação.

Programa C completo

#include <stdio.h>

int main(void) {
    float media;
    scanf("%f", &media);
    if (media >= 6.0f) {
        printf("Aprovado\n");
    } else {
        printf("Em recuperacao\n");
    }
    return 0;
}

Teste de mesa e depuração

media=6.0; 6.0>=6.0 é verdadeiro; imprime Aprovado. Teste também 5.9: a condição é falsa e imprime Em recuperacao.

Exercício 2 — Faixa de temperatura de máquina

Resposta esperada: 70.0 integra a faixa normal; acima desse valor é alta.

Programa C completo

#include <stdio.h>

int main(void) {
    float temperatura;
    scanf("%f", &temperatura);
    if (temperatura < 20.0f) {
        printf("Baixa\n");
    } else if (temperatura <= 70.0f) {
        printf("Normal\n");
    } else {
        printf("Alta\n");
    }
    return 0;
}

Teste de mesa e depuração

Com 70, o primeiro teste é falso e o segundo é verdadeiro. Teste 19.9, 20.0 e 70.1 para verificar as duas fronteiras.

Exercício 3 — Código de sensor válido

Resposta esperada: As duas comparações são verdadeiras para 1023.

Programa C completo

#include <stdio.h>

int main(void) {
    int codigo;
    scanf("%d", &codigo);
    if (codigo >= 0 && codigo <= 1023) {
        printf("Valido\n");
    } else {
        printf("Invalido\n");
    }
    return 0;
}

Teste de mesa e depuração

1023>=0 é verdadeiro e 1023<=1023 também. Com 1024, a segunda parte é falsa e o resultado é Invalido.

Exercício 4 — Prioridade de atendimento

Resposta esperada: O indicador 1 torna a condição verdadeira mesmo com idade abaixo de 60.

Programa C completo

#include <stdio.h>

int main(void) {
    int idade, deficiencia;
    scanf("%d %d", &idade, &deficiencia);
    if (idade >= 60 || deficiencia == 1) {
        printf("Prioritario\n");
    } else {
        printf("Comum\n");
    }
    return 0;
}

Teste de mesa e depuração

35>=60 é falso; 1==1 é verdadeiro; falso OU verdadeiro é verdadeiro. Com 35 e 0, o resultado é Comum.

Desafio opcional — Frete por região

Resposta esperada: A opção 3 seleciona o terceiro valor fixo; outras opções não têm frete calculado.

Programa C completo

#include <stdio.h>

int main(void) {
    int regiao;
    scanf("%d", &regiao);
    if (regiao == 1) {
        printf("Frete: R$ 0.00\n");
    } else if (regiao == 2) {
        printf("Frete: R$ 8.00\n");
    } else if (regiao == 3) {
        printf("Frete: R$ 15.00\n");
    } else {
        printf("Opcao invalida\n");
    }
    return 0;
}

Teste de mesa e depuração

Com regiao=3, os testes para 1 e 2 são falsos; o teste para 3 é verdadeiro e exibe R$ 15.00. Com regiao=4, todos os testes são falsos e a saída é Opcao invalida.
