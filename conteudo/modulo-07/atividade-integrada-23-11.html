Atividade Presencial — Módulo 7

2 h · Funções, parâmetros e retorno · 23/11/2026

Objetivo. Decompor cálculos em funções simples com parâmetros e retorno.

Este módulo ocupa o encontro presencial de 2 horas. O professor selecionará os exercícios para trabalho em aula e poderá retomar os demais depois.

Como resolver cada exercício

  1. Complete o quadro Entrada → Processamento → Saída.
  2. Esboce a lógica se isso ajudar; a escrita formal de pseudocódigo não é obrigatória.
  3. Implemente a solução em C com os recursos estudados até este módulo.
  4. Execute o programa com o caso de teste indicado e registre a saída.
  5. Faça o teste de mesa e compare a saída obtida com o resultado esperado.

Organização: são quatro exercícios e um desafio opcional. A lista é um repertório para seleção do professor, não uma exigência de resolver todos durante as 2 horas do encontro.

Exercício 1 — Custo de componentes

Crie a função float custoItens(int quantidade, float preco) para calcular os componentes. Crie também float custoTotal(int quantidade, float preco, float frete), que chama custoItens e soma o frete. Em main, leia quantidade, preço e frete não negativos; mostre custo dos itens e total.

EntradaProcessamentoSaída
Quantidade inteira de componentes e preço unitário e frete reais, todos não negativos.A função custoItens retorna quantidade × preço; a função custoTotal chama custoItens e soma o frete ao retorno.Exibir “Itens: R$ ...; total: R$ ...”, ambos com duas casas decimais.

Caso de teste: 6 unidades a R$ 2.50, frete R$ 3.00 → resultado esperado: Itens: R$ 15.00; total: R$ 18.00

Exercício 2 — Área de piso

Crie uma função float area(float largura, float comprimento) que retorna a área retangular. Leia as medidas positivas e mostre a área com duas casas.

EntradaProcessamentoSaída
Largura e comprimento positivos do piso, em metros (float).Chamar a função area(largura, comprimento), que devolve o produto das duas medidas.Exibir “Area: ... m2” com duas casas decimais.

Caso de teste: largura 3.5 m, comprimento 4.0 m → resultado esperado: Area: 14.00 m2

Exercício 3 — Maior de dois valores

Crie uma função int maior(int a, int b) que retorna o maior. Leia dois inteiros e exiba o retorno; em empate, pode retornar qualquer um porque são iguais.

EntradaProcessamentoSaída
Dois valores inteiros a e b.Chamar a função maior(a, b), que compara os valores e retorna o maior; em empate, ambos servem.Exibir “Maior: ...” com o inteiro retornado pela função.

Caso de teste: 12 e 19 → resultado esperado: Maior: 19

Exercício 4 — Procedimento de relatório

Crie um procedimento void mostrarRelatorio(int codigo, float valor) para imprimir código e valor. main lê os dois dados e chama o procedimento uma vez.

EntradaProcessamentoSaída
Código inteiro e valor real associado ao relatório.Ler os dois dados em main e passá-los ao procedimento mostrarRelatorio; o procedimento imprime e não retorna valor.Exibir uma linha “Codigo ...: R$ ...”, com o valor em duas casas decimais.

Caso de teste: código 42, valor R$ 18.75 → resultado esperado: Codigo 42: R$ 18.75

Desafio opcional — Função para verificar paridade

Crie int ehPar(int n), que retorna 1 para inteiro par e 0 para ímpar. Leia um número e imprima 'Par' ou 'Impar' conforme o retorno.

Caso de teste: n=14 → resultado esperado: Par

Entrega e conferência

Para os exercícios selecionados, mostre a análise do problema, o programa C, a saída obtida e um teste de mesa que explique o valor das variáveis. A escrita formal de pseudocódigo não é exigida.

Gabarito

Exercício 1 — Custo de componentes

Resposta esperada: custoItens retorna 15.00; custoTotal chama custoItens com os mesmos dados e retorna 15.00 + 3.00 = 18.00.

#include <stdio.h>

float custoItens(int quantidade, float preco) {
    return quantidade * preco;
}

float custoTotal(int quantidade, float preco, float frete) {
    return custoItens(quantidade, preco) + frete;
}

int main(void) {
    int quantidade;
    float preco, frete, itens, total;
    scanf("%d %f %f", &quantidade, &preco, &frete);
    itens = custoItens(quantidade, preco);
    total = custoTotal(quantidade, preco, frete);
    printf("Itens: R$ %.2f; total: R$ %.2f\n", itens, total);
    return 0;
}

Desafio opcional — Função para verificar paridade

Resposta esperada: 14%2=0, então a função retorna 1.

#include <stdio.h>

int ehPar(int n) {
    if (n % 2 == 0) {
        return 1;
    }
    return 0;
