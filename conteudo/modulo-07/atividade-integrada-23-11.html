EntradaProcessamentoSaída

Exercício 1 — Custo de componentes

Resposta esperada: custoItens retorna 15.00; custoTotal chama custoItens com os mesmos dados e retorna 15.00 + 3.00 = 18.00.

Programa C completo

#include <stdio.h>

float custoItens(int quantidade, float preco) {
    return quantidade * preco;
}

float custoTotal(int quantidade, float preco, float frete) {
    return custoItens(quantidade, preco) + frete;
}

int main(void) {
    int quantidade;
    float preco, frete, itens, total;
    scanf("%d %f %f", &quantidade, &preco, &frete);
    itens = custoItens(quantidade, preco);
    total = custoTotal(quantidade, preco, frete);
    printf("Itens: R$ %.2f; total: R$ %.2f\n", itens, total);
    return 0;
}

Teste de mesa e depuração

main lê 6, 2.50 e 3.00; custoItens(6, 2.50) retorna 15.00. Na chamada de custoTotal, a função chama custoItens(6, 2.50), recebe 15.00 e soma frete 3.00; retorna 18.00 a main. Confira separadamente as duas saídas para detectar dupla cobrança de frete.

Exercício 2 — Área de piso

Resposta esperada: A área é 3.5×4.0=14.00 m².

Programa C completo

#include <stdio.h>

float area(float largura, float comprimento) {
    return largura * comprimento;
}

int main(void) {
    float largura, comprimento;
    scanf("%f %f", &largura, &comprimento);
    printf("Area: %.2f m2\n", area(largura, comprimento));
    return 0;
}

Teste de mesa e depuração

Parâmetros recebem 3.5 e 4.0; a expressão retorna 14.0; printf formata com duas casas. A função não lê nem imprime dados: ela só calcula.

Exercício 3 — Maior de dois valores

Resposta esperada: 19 supera 12.

Programa C completo

#include <stdio.h>

int maior(int a, int b) {
    if (a >= b) {
        return a;
    }
    return b;
}

int main(void) {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("Maior: %d\n", maior(a, b));
    return 0;
}

Teste de mesa e depuração

a=12, b=19; 12>=19 é falso; execução chega a return b e devolve 19. Para 12 e 12, o primeiro retorno devolve 12.

Exercício 4 — Procedimento de relatório

Resposta esperada: A saída é produzida dentro do procedimento após a chamada.

Programa C completo

#include <stdio.h>

void mostrarRelatorio(int codigo, float valor) {
    printf("Codigo %d: R$ %.2f\n", codigo, valor);
}

int main(void) {
    int codigo;
    float valor;
    scanf("%d %f", &codigo, &valor);
    mostrarRelatorio(codigo, valor);
    return 0;
}

Teste de mesa e depuração

main lê 42 e 18.75; a chamada copia para codigo e valor do procedimento; printf imprime a linha; o controle volta a main. Não há return de valor em void.

Desafio opcional — Função para verificar paridade

Resposta esperada: 14%2=0, então a função retorna 1.

Programa C completo

#include <stdio.h>

int ehPar(int n) {
    if (n % 2 == 0) {
        return 1;
    }
    return 0;
}

int main(void) {
    int n;
    scanf("%d", &n);
    if (ehPar(n) == 1) {
        printf("Par\n");
    } else {
        printf("Impar\n");
    }
    return 0;
}

Teste de mesa e depuração

n=14 é passado à função; 14%2=0 torna a condição verdadeira; retorno=1; main escolhe Par. Com 15, retorno=0 e imprime Impar.
