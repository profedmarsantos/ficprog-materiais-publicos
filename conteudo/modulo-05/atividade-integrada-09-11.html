Exercício 1 — Soma de 1 até N

Resposta esperada: A sequência 1+2+3+4+5 soma 15.

Programa C completo

#include <stdio.h>

int main(void) {
    int n, i, soma = 0;
    scanf("%d", &n);
    for (i = 1; i <= n; i++) {
        soma = soma + i;
    }
    printf("Soma: %d\n", soma);
    return 0;
}

Teste de mesa e depuração

soma inicia em 0; após i=1,2,3,4,5, assume 1,3,6,10,15. Em i=6, 6<=5 é falso e o laço termina.

Exercício 2 — Contar valores até sentinela

Resposta esperada: Foram lidos três valores antes da sentinela.

Programa C completo

#include <stdio.h>

int main(void) {
    int valor, quantidade = 0;
    scanf("%d", &valor);
    while (valor != -1) {
        quantidade++;
        scanf("%d", &valor);
    }
    printf("Quantidade: %d\n", quantidade);
    return 0;
}

Teste de mesa e depuração

Com 4, quantidade=1; com 0, quantidade=2; com 9, quantidade=3; com -1, a condição falha. Se a primeira entrada for -1, imprime 0.

Exercício 3 — Menu até sair

Resposta esperada: O menu processa três opções; a última encerra a repetição.

Programa C completo

#include <stdio.h>

int main(void) {
    int opcao;
    do {
        scanf("%d", &opcao);
        if (opcao == 1) {
            printf("Continuar\n");
        } else if (opcao == 0) {
            printf("Sair\n");
        } else {
            printf("Opcao invalida\n");
        }
    } while (opcao != 0);
    return 0;
}

Teste de mesa e depuração

Na primeira volta, opção=1 e o laço continua; na segunda, 7 também continua; na terceira, 0 imprime Sair e a condição final é falsa. Mesmo 0 como primeira entrada é processado uma vez.

Exercício 4 — Contar dígitos decimais

Resposta esperada: 4052 → 405 → 40 → 4, portanto quatro dígitos.

Programa C completo

#include <stdio.h>

int main(void) {
    int n, digitos = 1;
    scanf("%d", &n);
    while (n >= 10) {
        n = n / 10;
        digitos++;
    }
    printf("Digitos: %d\n", digitos);
    return 0;
}

Teste de mesa e depuração

n=4052, digitos=1; iterações: (405,2), (40,3), (4,4). Como 4>=10 é falso, imprime 4. Para n=0, nenhuma iteração ocorre e a resposta fica 1.

Desafio opcional — Tabuada de um número

Resposta esperada: O multiplicador percorre todos os valores de 1 a 10, inclusive.

Programa C completo

#include <stdio.h>

int main(void) {
    int n, i;
    scanf("%d", &n);
    for (i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", n, i, n * i);
    }
    return 0;
}

Teste de mesa e depuração

Com n=3, i=1 imprime 3; i=2 imprime 6; ... i=10 imprime 30. O próximo i=11 falha na condição e nenhuma linha extra aparece.
