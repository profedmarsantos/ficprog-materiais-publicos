Atividade Presencial — Módulo 5

2 h · Estruturas de repetição · 09/11/2026

Objetivo. Selecionar e rastrear estruturas de repetição conforme a condição de parada.

Este módulo ocupa o encontro presencial de 2 horas. O professor selecionará os exercícios para trabalho em aula e poderá retomar os demais depois.

Como resolver cada exercício

  1. Complete o quadro Entrada → Processamento → Saída.
  2. Esboce a lógica se isso ajudar; a escrita formal de pseudocódigo não é obrigatória.
  3. Implemente a solução em C com os recursos estudados até este módulo.
  4. Execute o programa com o caso de teste indicado e registre a saída.
  5. Faça o teste de mesa e compare a saída obtida com o resultado esperado.

Organização: são quatro exercícios e um desafio opcional. A lista é um repertório para seleção do professor, não uma exigência de resolver todos durante as 2 horas do encontro.

Exercício 1 — Soma de 1 até N

Leia N inteiro de 1 a 100. Some os inteiros de 1 a N com for e mostre o total.

EntradaProcessamentoSaída
Limite N (int, de 1 a 100).Iniciar acumulador em zero; percorrer os inteiros de 1 até N com for e acrescentar cada valor ao acumulador.Exibir “Soma: ...” com o total inteiro de 1 até N.

Caso de teste: N=5 → resultado esperado: Soma: 15

Exercício 2 — Contar valores até sentinela

Leia inteiros não negativos até receber -1. Mostre quantos valores válidos foram lidos. O -1 encerra e não entra na contagem.

EntradaProcessamentoSaída
Sequência de inteiros não negativos, encerrada pelo valor sentinela -1.Ler e contar cada valor antes da sentinela; ao encontrar -1, encerrar sem incluí-lo na contagem.Exibir “Quantidade: ...” com o número inteiro de valores válidos lidos.

Caso de teste: 4, 0, 9, -1 → resultado esperado: Quantidade: 3

Exercício 3 — Menu até sair

Leia repetidamente uma opção inteira com do while. A opção 1 mostra 'Continuar'; a opção 0 mostra 'Sair' e encerra. Para outra opção, mostre 'Opcao invalida'.

EntradaProcessamentoSaída
Sequência de opções inteiras do menu, terminada pela opção 0.Executar o menu ao menos uma vez com do while; mostrar Continuar para 1, Sair para 0 e Opcao invalida para outro número.Exibir uma mensagem por opção lida, em linhas separadas; a opção 0 também produz “Sair”.

Caso de teste: 1, 7, 0 → resultado esperado: Continuar; Opcao invalida; Sair (uma mensagem por linha)

Exercício 4 — Contar dígitos decimais

Leia inteiro não negativo. Conte seus dígitos em base 10 usando while. O número 0 possui um dígito.

EntradaProcessamentoSaída
Número inteiro N não negativo.Iniciar a contagem em 1 para incluir o caso N = 0; dividir N por 10 enquanto ele tiver ao menos dois dígitos, aumentando a contagem.Exibir “Digitos: ...” com a quantidade inteira de algarismos decimais.

Caso de teste: N=4052 → resultado esperado: Digitos: 4

Desafio opcional — Tabuada de um número

Leia N inteiro de 0 a 10. Mostre os dez produtos N×1 até N×10, um por linha, usando for.

Caso de teste: N=3 → resultado esperado: Dez linhas: primeira 3 x 1 = 3; última 3 x 10 = 30

Entrega e conferência

Para os exercícios selecionados, mostre a análise do problema, o programa C, a saída obtida e um teste de mesa que explique o valor das variáveis. A escrita formal de pseudocódigo não é exigida.

Gabarito

Abra cada solução depois da tentativa dos estudantes. Os programas usam apenas os recursos introdutórios estudados até este módulo.

Exercício 1 — Soma de 1 até N

Resposta esperada: A sequência 1+2+3+4+5 soma 15.

#include <stdio.h>

int main(void) {
    int n, i, soma = 0;
    scanf("%d", &n);
    for (i = 1; i <= n; i++) {
        soma = soma + i;
    }
    printf("Soma: %d\n", soma);
    return 0;
}

Exercício 3 — Menu até sair

Resposta esperada: O menu processa três opções; a última encerra a repetição.

#include <stdio.h>

int main(void) {
    int opcao;
    do {
        scanf("%d", &opcao);
        if (opcao == 1) {
            printf("Continuar\n");
        } else if (opcao == 0) {
            printf("Sair\n");
        } else {
            printf("Opcao invalida\n");
        }
    } while (opcao != 0);
    return 0;
}
