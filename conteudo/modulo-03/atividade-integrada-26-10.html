Atividade Presencial — Módulo 3

2 h · Estrutura sequencial e múltiplas entradas e saídas · 26/10/2026

Objetivo. Organizar algoritmos sequenciais com múltiplas entradas, cálculos intermediários e saídas.

Este módulo compartilha as 2 horas presenciais do encontro com o Módulo 4. O professor selecionará os exercícios a trabalhar em aula; os demais ficam para estudo e retomada.

Como resolver cada exercício

  1. Complete o quadro Entrada → Processamento → Saída.
  2. Esboce a lógica se isso ajudar; a escrita formal de pseudocódigo não é obrigatória.
  3. Implemente a solução em C com os recursos estudados até este módulo.
  4. Execute o programa com o caso de teste indicado e registre a saída.
  5. Faça o teste de mesa e compare a saída obtida com o resultado esperado.

Organização: são quatro exercícios e um desafio opcional. A lista é um repertório para seleção do professor, não uma exigência de resolver todos durante as 2 horas do encontro.

Entrega e conferência

Para os exercícios selecionados, mostre a análise do problema, o programa C, a saída obtida e um teste de mesa que explique o valor das variáveis. A escrita formal de pseudocódigo não é exigida.

Gabarito

Exercício 1 — Ordem de serviço

Resposta esperada: Os dois parciais são 25.00 e 12.00; com a mão de obra, o total é 57.00.

Programa C completo

#include <stdio.h>

int main(void) {
    int q1, q2;
    float p1, p2, maoObra, parcial1, parcial2, total;
    scanf("%d %f %d %f %f", &q1, &p1, &q2, &p2, &maoObra);
    parcial1 = q1 * p1;
    parcial2 = q2 * p2;
    total = parcial1 + parcial2 + maoObra;
    printf("Peca 1: R$ %.2f; peca 2: R$ %.2f; total: R$ %.2f\n",
           parcial1, parcial2, total);
    return 0;
}

Exercício 2 — Leituras de temperatura

Resposta esperada: 25 °C correspondem a 77 °F e 298.15 K.

Programa C completo

#include <stdio.h>

int main(void) {
    float celsius, fahrenheit, kelvin;
    scanf("%f", &celsius);
    fahrenheit = celsius * 9.0f / 5.0f + 32.0f;
    kelvin = celsius + 273.15f;
    printf("Fahrenheit: %.2f F; Kelvin: %.2f K\n",
           fahrenheit, kelvin);
    return 0;
}

Teste de mesa e depuração

PassocelsiusfahrenheitkelvinSaída
Leitura25.0———
Atribuição: fahrenheit = celsius × 9 / 5 + 3225.077.0——
Atribuição: kelvin = celsius + 273.1525.077.0298.15—
Exibição25.077.0298.15Fahrenheit: 77.00 F; Kelvin: 298.15 K

Conferência e depuração: Com celsius=25, a multiplicação por 9/5 dá 45; somando 32, fahrenheit=77. Kelvin=25+273.15=298.15. Confira a ordem das operações para não somar 32 antes da multiplicação.

Exercício 3 — Balanço de um reservatório

Resposta esperada: A entrada é somada antes de subtrair o consumo.

Programa C completo

#include <stdio.h>

int main(void) {
    float inicial, entrada, consumo, disponivel, final;
    scanf("%f %f %f", &inicial, &entrada, &consumo);
    disponivel = inicial + entrada;
    final = disponivel - consumo;
    printf("Disponivel: %.2f L; final: %.2f L\n", disponivel, final);
    return 0;
}

Exercício 4 — Pedido de impressão

Resposta esperada: A contagem total é 24 e o custo é 3.00 + 3.20 = 6.20.

Programa C completo

#include <stdio.h>

int main(void) {
    int pB, pC, paginas;
    float precoB, precoC, custo;
    scanf("%d %f %d %f", &pB, &precoB, &pC, &precoC);
    paginas = pB + pC;
    custo = pB * precoB + pC * precoC;
    printf("Paginas: %d; custo: R$ %.2f\n", paginas, custo);
    return 0;
}

Conferência e depuração: pB=20, pC=4, páginas=24. Parcial P&B=20×0.15=3.00; colorida=4×0.80=3.20; custo=6.20. Preços e quantidades precisam ficar associados à modalidade correta.
