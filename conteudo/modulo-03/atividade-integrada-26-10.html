Exercício 1 — Ordem de serviço

Resposta esperada: Os dois parciais são 25.00 e 12.00; com a mão de obra, o total é 57.00.

Programa C completo

#include <stdio.h>

int main(void) {
    int q1, q2;
    float p1, p2, maoObra, parcial1, parcial2, total;
    scanf("%d %f %d %f %f", &q1, &p1, &q2, &p2, &maoObra);
    parcial1 = q1 * p1;
    parcial2 = q2 * p2;
    total = parcial1 + parcial2 + maoObra;
    printf("Peca 1: R$ %.2f; peca 2: R$ %.2f; total: R$ %.2f\n",
           parcial1, parcial2, total);
    return 0;
}

Teste de mesa e depuração

Após a leitura, parcial1=2×12.50=25.00; parcial2=3×4.00=12.00; total=25+12+20=57. Calcular o total antes dos parciais usaria valores ainda não definidos.

Exercício 2 — Leituras de temperatura

Resposta esperada: 25 °C correspondem a 77 °F e 298.15 K.

Programa C completo

#include <stdio.h>

int main(void) {
    float celsius, fahrenheit, kelvin;
    scanf("%f", &celsius);
    fahrenheit = celsius * 9.0f / 5.0f + 32.0f;
    kelvin = celsius + 273.15f;
    printf("Fahrenheit: %.2f F; Kelvin: %.2f K\n",
           fahrenheit, kelvin);
    return 0;
}

Teste de mesa e depuração

Com celsius=25, a multiplicação por 9/5 dá 45; somando 32, fahrenheit=77. Kelvin=25+273.15=298.15. Confira a ordem das operações para não somar 32 antes da multiplicação.

Exercício 3 — Balanço de um reservatório

Resposta esperada: A entrada é somada antes de subtrair o consumo.

Programa C completo

#include <stdio.h>

int main(void) {
    float inicial, entrada, consumo, disponivel, final;
    scanf("%f %f %f", &inicial, &entrada, &consumo);
    disponivel = inicial + entrada;
    final = disponivel - consumo;
    printf("Disponivel: %.2f L; final: %.2f L\n", disponivel, final);
    return 0;
}

Teste de mesa e depuração

Após a leitura: inicial=80, entrada=25.5, consumo=40. Disponível recebe 105.5; final recebe 65.5. Se subtrair antes de somar, o total pode coincidir, mas deixa de representar corretamente o estado intermediário pedido.

Exercício 4 — Pedido de impressão

Resposta esperada: A contagem total é 24 e o custo é 3.00 + 3.20 = 6.20.

Programa C completo

#include <stdio.h>

int main(void) {
    int pB, pC, paginas;
    float precoB, precoC, custo;
    scanf("%d %f %d %f", &pB, &precoB, &pC, &precoC);
    paginas = pB + pC;
    custo = pB * precoB + pC * precoC;
    printf("Paginas: %d; custo: R$ %.2f\n", paginas, custo);
    return 0;
}

Teste de mesa e depuração

pB=20, pC=4, páginas=24. Parcial P&B=20×0.15=3.00; colorida=4×0.80=3.20; custo=6.20. Preços e quantidades precisam ficar associados à modalidade correta.

Desafio opcional — Kit com embalagem e frete

Resposta esperada: Produtos somam 31.00, adicionais somam 8.50, total 39.50.

Programa C completo

#include <stdio.h>

int main(void) {
    int q1, q2;
    float p1, p2, embalagem, frete, produtos, adicionais, total;
    scanf("%d %f %d %f %f %f", &q1, &p1, &q2, &p2, &embalagem, &frete);
    produtos = q1 * p1 + q2 * p2;
    adicionais = embalagem + frete;
    total = produtos + adicionais;
    printf("Produtos: R$ %.2f; adicionais: R$ %.2f; total: R$ %.2f\n",
           produtos, adicionais, total);
    return 0;
}

Teste de mesa e depuração

produtos=2×8+1×15=31; adicionais=2.50+6=8.50; total=39.50. Confira se cada saída usa a variável correspondente.
