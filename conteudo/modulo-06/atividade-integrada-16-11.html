Atividade Presencial — Módulo 6

2 h · Vetores, indexação e iteração · 16/11/2026

Objetivo. Percorrer vetores, acessar índices válidos e obter resultados a partir dos elementos.

Este módulo ocupa o encontro presencial de 2 horas. O professor selecionará os exercícios para trabalho em aula e poderá retomar os demais depois.

Como resolver cada exercício

  1. Complete o quadro Entrada → Processamento → Saída.
  2. Esboce a lógica se isso ajudar; a escrita formal de pseudocódigo não é obrigatória.
  3. Implemente a solução em C com os recursos estudados até este módulo.
  4. Execute o programa com o caso de teste indicado e registre a saída.
  5. Faça o teste de mesa e compare a saída obtida com o resultado esperado.

Organização: são quatro exercícios e um desafio opcional. A lista é um repertório para seleção do professor, não uma exigência de resolver todos durante as 2 horas do encontro.

Leia cinco temperaturas reais em um vetor. Mostre a média aritmética com duas casas. Use dois percursos: leitura e soma.

Desafio opcional — Primeira ocorrência

Leia cinco códigos inteiros e um código procurado. Mostre o primeiro índice onde ele aparece ou -1 se não existir. Preserve a primeira ocorrência mesmo se houver repetições.

Caso de teste: vetor 4, 7, 4, 9, 4; procura 4 → resultado esperado: Indice: 0

Entrega e conferência

Para os exercícios selecionados, mostre a análise do problema, o programa C, a saída obtida e um teste de mesa que explique o valor das variáveis. A escrita formal de pseudocódigo não é exigida.

Gabarito

Abra cada solução depois da tentativa dos estudantes. Os programas usam apenas os recursos introdutórios estudados até este módulo.

Exercício 1 — Média de cinco temperaturas

Resposta esperada: A soma é 120 e a média é 24.

Programa C completo

#include <stdio.h>

int main(void) {
    float temp[5], soma = 0.0f;
    int i;
    for (i = 0; i < 5; i++) {
        scanf("%f", &temp[i]);
    }
    for (i = 0; i < 5; i++) {
        soma += temp[i];
    }
    printf("Media: %.2f\n", soma / 5.0f);
    return 0;
}

Exercício 2 — Menor leitura

Resposta esperada: O valor 2, na posição 3, é o menor.

Programa C completo

#include <stdio.h>

int main(void) {
    int medicao[6], i, minimo;
    for (i = 0; i < 6; i++) {
        scanf("%d", &medicao[i]);
    }
    minimo = medicao[0];
    for (i = 1; i < 6; i++) {
        if (medicao[i] < minimo) {
            minimo = medicao[i];
        }
    }
    printf("Menor: %d\n", minimo);
    return 0;
}

Exercício 3 — Exibir ordem inversa

Resposta esperada: A saída percorre índices 4, 3, 2, 1, 0.

Programa C completo

#include <stdio.h>

int main(void) {
    int codigo[5], i;
    for (i = 0; i < 5; i++) {
        scanf("%d", &codigo[i]);
    }
    for (i = 4; i >= 0; i--) {
        printf("%d", codigo[i]);
        if (i > 0) {
            printf(" ");
        }
    }
    printf("\n");
    return 0;
}

Após a leitura, codigo[0]=11 e codigo[4]=55. A segunda repetição visita 4→0 e imprime 55,44,33,22,11. A condição i>=0 inclui a primeira posição.

Exercício 4 — Contagem no limite ou acima

Resposta esperada: Notas 7, 6 e 8 atingem o limite.

Programa C completo

#include <stdio.h>

int main(void) {
    float nota[5], limite;
    int i, quantidade = 0;
    for (i = 0; i < 5; i++) {
        scanf("%f", &nota[i]);
    }
    scanf("%f", &limite);
    for (i = 0; i < 5; i++) {
        if (nota[i] >= limite) {
            quantidade++;
        }
    }
    printf("Quantidade: %d\n", quantidade);
    return 0;
}

Com limite=6, índices 0 e 4 não contam; 1,2,3 contam. Quantidade evolui 0,1,2,3,3. O operador >= inclui a nota exatamente igual a 6.

Desafio opcional — Primeira ocorrência

Resposta esperada: O primeiro 4 está no índice 0.

Programa C completo

#include <stdio.h>

int main(void) {
    int codigo[5], procurado, indice = -1, i;
    for (i = 0; i < 5; i++) {
        scanf("%d", &codigo[i]);
    }
    scanf("%d", &procurado);
    for (i = 0; i < 5; i++) {
        if (codigo[i] == procurado && indice == -1) {
            indice = i;
        }
    }
    printf("Indice: %d\n", indice);
    return 0;
}

No índice 0, encontra 4 e grava 0. Nos índices 2 e 4, a condição indice==-1 já é falsa, portanto o valor 0 permanece. Se nada coincidir, imprime -1.
