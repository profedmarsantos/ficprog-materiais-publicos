Objetivo. Integrar decisões, laços, vetores e funções em problemas práticos.

Este módulo ocupa o encontro presencial de 2 horas. O professor selecionará os exercícios para trabalho em aula e poderá retomar os demais depois.

Como resolver cada exercício

  1. Complete o quadro Entrada → Processamento → Saída.
  2. Esboce a lógica se isso ajudar; a escrita formal de pseudocódigo não é obrigatória.
  3. Implemente a solução em C com os recursos estudados até este módulo.
  4. Execute o programa com o caso de teste indicado e registre a saída.
  5. Faça o teste de mesa e compare a saída obtida com o resultado esperado.

Organização: são quatro exercícios e um desafio opcional. A lista é um repertório para seleção do professor, não uma exigência de resolver todos durante as 2 horas do encontro.

Exercício 1 — Caixa eletrônico

Leia saldo inicial real não negativo e três pedidos de saque reais. Em cada pedido, aceite apenas valor positivo que não ultrapasse o saldo atual. Mostre quantos saques foram aceitos e o saldo final.

EntradaProcessamentoSaída
saldo e três pedidospara cada pedido, testar 0 < saque <= saldo; se aceito, subtrair e contarsaques aceitos e saldo final

Caso de teste: saldo 100.00; pedidos 30.00, 80.00, 20.00 → resultado esperado: Saques aceitos: 2; saldo: R$ 50.00

Exercício 2 — Posto de gasolina

Leia preço real por litro e três volumes abastecidos, todos não negativos. Some os litros, calcule o valor bruto e conceda 5% de desconto se o bruto for pelo menos R$ 200. Mostre litros e total a pagar.

EntradaProcessamentoSaída
preço/litro e três volumessomar litros; bruto=litros*preço; se bruto>=200, pagar=bruto*0.95litros e pagamento

Caso de teste: R$ 5.00/L; 10, 15 e 20 L → resultado esperado: Litros: 45.00; pagar: R$ 213.75

Exercício 3 — Controle de estacionamento

Leia as horas inteiras de permanência de três carros, cada uma maior que zero, em um vetor. A primeira hora custa R$ 5 e cada hora adicional R$ 3. Crie uma função que calcule a tarifa de um carro e mostre a receita total.

EntradaProcessamentoSaída

Caso de teste: 1, 2 e 4 horas → resultado esperado: Receita: R$ 27.00

Exercício 4 — Painel de medições

Leia cinco medições reais em um vetor e um limite real. Calcule média, maior valor e quantidade de leituras maiores ou iguais ao limite. Use uma função simples para decidir se uma leitura está em alerta.

Caso de teste: 18, 22, 19, 25, 16; limite 20 → resultado esperado: Media: 20.00; maior: 25.00; alertas: 2

Desafio opcional — Meta de produção

Leia uma meta diária inteira positiva e a produção inteira não negativa de três dias em um vetor. Crie função int atingiuMeta(int producao, int meta) que retorne 1 se a meta foi atingida. Mostre a produção total e quantos dias atingiram a meta.

Caso de teste: meta 10; produções 8, 10 e 13 → resultado esperado: Producao total: 31; dias na meta: 2

Exercício 1 — Caixa eletrônico

Resposta esperada: 30 é aceito (saldo 70), 80 é recusado, 20 é aceito (saldo 50).

Programa C completo

#include <stdio.h>

int main(void) {
    float saldo, saque;
    int i, aceitos = 0;
    scanf("%f", &saldo);
    for (i = 0; i < 3; i++) {
        scanf("%f", &saque);
        if (saque > 0.0f && saque <= saldo) {
            saldo = saldo - saque;
            aceitos++;
        }
    }
    printf("Saques aceitos: %d; saldo: R$ %.2f\n", aceitos, saldo);
    return 0;
}

Exercício 2 — Posto de gasolina

Resposta esperada: 45 L custam R$ 225.00; desconto de R$ 11.25; pagar R$ 213.75.

Programa C completo

#include <stdio.h>

int main(void) {
    float preco, litros, volume, bruto, pagar;
    int i;
    scanf("%f", &preco);
    litros = 0.0f;
    for (i = 0; i < 3; i++) {
        scanf("%f", &volume);
        litros += volume;
    }
    bruto = litros * preco;
    pagar = bruto;
    if (bruto >= 200.0f) {
        pagar = bruto * 0.95f;
    }
    printf("Litros: %.2f; pagar: R$ %.2f\n", litros, pagar);
    return 0;
}

Exercício 3 — Controle de estacionamento

Resposta esperada: Tarifas 5, 8 e 14 totalizam 27.

Programa C completo

#include <stdio.h>

float tarifa(int horas) {
    return 5.0f + (horas - 1) * 3.0f;
}

int main(void) {
    int horas[3], i;
    float receita = 0.0f;
    for (i = 0; i < 3; i++) {
        scanf("%d", &horas[i]);
    }
    for (i = 0; i < 3; i++) {
        receita += tarifa(horas[i]);
    }
    printf("Receita: R$ %.2f\n", receita);
    return 0;
}

Exercício 4 — Painel de medições

Resposta esperada: A soma é 100, a média 20, o maior 25 e duas leituras atingem o limite.

Programa C completo

#include <stdio.h>

int emAlerta(float valor, float limite) {
    if (valor >= limite) {
        return 1;
    }
    return 0;
}

int main(void) {
    float medicao[5], limite, soma = 0.0f, maior;
    int i, alertas = 0;
    for (i = 0; i < 5; i++) {
        scanf("%f", &medicao[i]);
    }
    scanf("%f", &limite);
    maior = medicao[0];
    for (i = 0; i < 5; i++) {
        soma += medicao[i];
        if (medicao[i] > maior) {
            maior = medicao[i];
        }
        alertas += emAlerta(medicao[i], limite);
    }
    printf("Media: %.2f; maior: %.2f; alertas: %d\n",
           soma / 5.0f, maior, alertas);
    return 0;
}

Desafio opcional — Meta de produção

Resposta esperada: Somam-se 31 unidades; os dias 2 e 3 atingem a meta.

Programa C completo

#include <stdio.h>

int atingiuMeta(int producao, int meta) {
    if (producao >= meta) {
        return 1;
    }
    return 0;
}

int main(void) {
    int meta, producao[3], total = 0, dias = 0, i;
    scanf("%d", &meta);
    for (i = 0; i < 3; i++) {
        scanf("%d", &producao[i]);
    }
    for (i = 0; i < 3; i++) {
        total += producao[i];
        dias += atingiuMeta(producao[i], meta);
    }
    printf("Producao total: %d; dias na meta: %d\n", total, dias);
    return 0;
}

Exploração opcional — Arduino no Tinkercad Circuits

Esta exploração não compõe os quatro exercícios, o desafio, a lista Moodle ou o questionário. Se quiser observar a relação entre algoritmo e dispositivo físico, abra Tinkercad Circuits, crie uma simulação com Arduino e use o editor em modo texto. O exemplo abaixo alterna o estado do pino digital 13 a cada segundo. Inicie a simulação e observe a saída correspondente; não há entrega nem avaliação posterior.

void setup() {
    pinMode(13, OUTPUT);
}

void loop() {
    digitalWrite(13, HIGH);
    delay(1000);
    digitalWrite(13, LOW);
    delay(1000);
}

Esse trecho usa funções próprias do ambiente Arduino e é apenas uma demonstração opcional, posterior à integração dos programas C.
